Pricing Card

Product metadata becomes visual priority, accent color, badge, and discount meter. 

          <article is="back-plan" data-plan="pro" data-popular="true" data-discount="20">
            <h2>Pro</h2>
            <p>For real product teams.</p>
          </article>
        

          [is='back-plan'] {
            --plan: attr(data-plan type(<custom-ident>), starter);
            --popular: attr(data-popular type(<custom-ident>), false);
            --discount: attr(data-discount type(<number>), 0);

            --accent: if(style(--plan: starter): #2fbfff; style(--plan: pro): #1252ff; style(--plan: enterprise): #7b4fff; else: #667085;);

            border-color: if(style(--popular: true): var(--accent); else: #eaecf0;);
            box-shadow: if(style(--popular: true): 0 1.5rem 3rem oklch(from var(--accent) l c h / 0.24); else: 0 0.5rem 1.5rem rgb(16 24 40 / 0.06););
          }

          [is='back-plan']::after {
            content: "";
            display: block;
            inline-size: calc(clamp(0, var(--discount), 100) * 1%);
            block-size: 0.35rem;
            background: var(--accent);
          }
