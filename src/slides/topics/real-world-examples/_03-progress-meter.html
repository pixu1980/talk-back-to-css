Progress Meter

A number attribute feeds a computed percentage, while state controls the tone. 

          <div is="back-meter" data-label="Build health" data-value="82" data-state="success"></div>
          <div is="back-meter" data-label="Storage usage" data-value="64" data-state="warning"></div>
          <div is="back-meter" data-label="Error budget" data-value="24" data-state="danger"></div>
        

          [is='back-meter'] {
            --value: attr(data-value type(<number>), 0);
            --state: attr(data-state type(<custom-ident>), info);

            --accent: if(style(--state: danger): #d92d20; style(--state: warning): #f79009; style(--state: success): #079455; else: #1252ff;);
          }

          [is='back-meter']::after {
            content: "";
            display: block;
            block-size: 0.9rem;
            border-radius: 999px;
            background: linear-gradient(90deg, var(--accent) 0 calc(clamp(0, var(--value), 100) * 1%), #eaecf0 0);
          }
