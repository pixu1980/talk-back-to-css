Editorial Callout

A CMS or markdown renderer emits semantic attributes - CSS builds the visual treatment. 

          <aside is="back-callout" data-tone="warning" data-emphasis="soft" data-gap="5" data-icon="!">
            <strong>Experimental CSS ahead.</strong>
            Use this demo in a controlled browser environment.
          </aside>
        

          [is='back-callout'] {
            --tone: attr(data-tone type(<custom-ident>), info);
            --emphasis: attr(data-emphasis type(<custom-ident>), soft);
            --gap: attr(data-gap type(<number>), 4);

            --accent: if(style(--tone: warning): #f79009; else: #1252ff;);
            --surface: if(style(--emphasis: solid): var(--accent); else: oklch(from var(--accent) l c h / 0.12););
            --ink: if(style(--emphasis: solid): white; else: #101828;);

            display: grid;
            grid-template-columns: auto 1fr;
            gap: calc(var(--gap) * 0.25rem);
            padding: calc(var(--gap) * 0.25rem);
            border: 1px solid oklch(from var(--accent) l c h / 0.4);
            background: var(--surface);
            color: var(--ink);
          }
