Responsive Grid

The markup expresses the desired layout - CSS decides what the container can afford. 

          <div class="grid-preview">
            <section is="back-grid" data-cols="4" data-gap="4" data-density="comfortable">
              <article>Design tokens</article>
              <article>Components</article>
              <article>Patterns</article>
              <article>Guidelines</article>
            </section>
          </div>
        

          .grid-preview {
            container-type: inline-size;
            resize: horizontal;
            overflow: auto;
          }

          [is='back-grid'] {
            --columns: attr(data-cols type(<integer>), 3);
            --gap-step: attr(data-gap type(<number>), 4);
            --density: attr(data-density type(<custom-ident>), comfortable);

            display: grid;
            gap: calc(var(--gap-step) * 0.25rem);
            grid-template-columns: repeat(var(--columns), minmax(0, 1fr));
          }

          @container (width < 700px) {
            [is='back-grid'] {
              grid-template-columns: 1fr;
            }
          }
